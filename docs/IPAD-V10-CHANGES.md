# V10.0 Lite 变更

- 明确拒绝、成功、未决和主动停止都有独立运行编号。本站保存最近 30 次脱敏诊断。历史浏览、复制和清理均在本机完成。
- HTTP 404 保留 HTTP 状态、业务码与未决保护，可以核验官方记录。泛指账号「无法预约」的拒绝会保留为业务失败。已核验的记录遇到后续读取异常时保留上次匹配事实。
- 读超时、读 404 与写超时分别记录。可用时记录浏览器请求起点、首字节等待和响应下载耗时。未知字段显示 null。
- 在原账号锁内检查已有未决或有效申请是否与本次时段重叠。原有签名、六字段表单、默认整点及一次提交约束继续适用。同一任务没有自动补发。沿用 V9 已有的人工补交条件。
- 页面恢复时按北京日期和实际时间继续判断。跨日结束，零提交可重新启动。诊断记录墙钟相对单调时钟的变化；系统时间由设备设置。
- iPadOS 真机安装、系统休眠、高峰网络与官方记录验收状态为 REAL_DEVICE_PENDING。
