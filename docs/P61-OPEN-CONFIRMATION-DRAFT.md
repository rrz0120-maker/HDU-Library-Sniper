# P6.1 开放确认验收
P6.0 基线 d144d479c6daeef61314ffe6e72beaf436560291，P6.1 候选基线 38bee8104fc131d04de66dbd64ef1b1ff01f6d33。
11-19：客户端 20:00:00.440 发出，20:00:00.550 NOT_OPEN；20:00:00.743 本地显示 FAILED，之后降级 UNKNOWN。NOT_OPEN 按 ParamError 文案分类，不能确定业务服务器准确开放时间。
设计：原时钟门禁通过后仅核验原馆方只读日期范围，max_date 是排除上界；必须明确包含目标日期并符合时段、时长和类目。明确仍闭时至少间隔 1 秒最多再读一次，查询异常停止；仍受原保守窗口限制。唯一正式预约不变。日期范围已开放不保证具体座位可预约或业务端一定接受。
修复：停止保留持久化终态；仅对存在明确 NOT_OPEN、原 FAILED 证据且无成功证据的旧任务，用户主动查看结果并成功完成新一次官方记录不存在核验后，事务恢复 FAILED。保留原尝试次数、查询预算，不重置历史。如果核验额度耗尽继续阻断。
验收通过：核心 96 项，Firefox P6.1 29 项、P5.3 18 项、P5.2 11 项。Firefox 实测 P6.0 安装文件生成的历史 UNKNOWN 在记录查询失败时保持阻断，显式复核确认无记录后恢复 FAILED，保留原提交和核验次数。校验使用 Mock，真实服务器写入为零。构建、语法、类型检查通过。
