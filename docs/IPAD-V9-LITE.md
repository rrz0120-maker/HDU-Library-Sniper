# HDU iPad V9 Lite 使用说明

V9 使用当前 Safari 已登录的馆方会话，预约宋韵云图（四楼）162 号。整点默认在北京时间 20:00:01.200 发出预约，目标为开放日后天的 09:00–22:00。可选 07:00–22:00 内的整点时段，包括 08:00–22:00。

## 安装

1. 在 iPad 启用 Userscripts 的 Safari 扩展，在 Userscripts 中选定脚本目录。
2. 保存 `HDU_iPad_V9_Lite.user.js` 到该目录，保留 `.user.js` 后缀，并在扩展中启用。首次打开馆方站点时，允许扩展在该站点运行。[下载安装文件](https://raw.githubusercontent.com/rrz0120-maker/HDU-Library-Sniper/feat/ipad-v9-lite-from-proven-mobile/userscripts/HDU_iPad_V9_Lite.user.js)
3. 在扩展里停用之前的 HDU 预约脚本，关闭已有馆方标签页。新开馆方页面并正常登录，右下角应出现「162 预约」。若显示「检测到旧版」，停用旧版后重新打开页面。[杭电预约官网](https://hdu.huitu.zhishulib.com/)

运行环境需要支持 Web Locks 的 Safari（iPadOS 15.4 起）和可写的站点存储。旧标签页、其他设备或另一浏览器配置文件中已经运行的程序需分别停止。

## 使用

- **整点预约**　在 20:00 前展开面板，选择开始、结束时间和偏移量（800–2000 毫秒），看清目标日期，点「启动 20:00 预约」。看到「等待20:00」即已完成准备。Safari 保持前台，屏幕常亮，系统日期与时间使用自动设置。可收起面板继续操作官网。
- **已开放时段测试**　选择此模式后，面板显示最近一次 20:00 已开放的目标日期。开放前是明天，开放后是后天。点「立即真实预约」即授权本次实际写入，请先核对日期和时段。
- **停止与恢复**　正式请求发出前可停止并重新启动。短暂离开页面会保留待命。若系统暂停网页，同一北京时间自然日恢复前台后会按当时的实际时间发送，迟到会标记为超窗。跨日恢复会显示未发送。发出请求后可等待回执，刷新后可点「核验官方记录」。
- **查看结果**　「正在发送」表示浏览器已接手 POST。「服务器已受理」表示馆方返回 `CODE=ok` 且 `DATA.result=success`。「预约成功且记录已核验」表示官方有效记录与日期、时段、房间和 162 号座位匹配。页面显示本次业务原文。点「复制诊断日志」导出脱敏 JSON，剪贴板不可用时可长按文本复制。

## 失败后的行为

| 返回 | 面板与写入行为 |
| --- | --- |
| `NOT_OPEN` | 显示尚未开放并结束本次运行。要补交，用户须重新点「立即真实预约」。同一目标最多一次人工补交，须已过写入间隔、未处于限流期，且馆方只读日期和时段范围明确允许。 |
| `SEAT_UNAVAILABLE` | 显示馆方拒绝原因，结束本次 162 号申请。 |
| `LIMITED` 或 HTTP 429 | 立即停止。按实测封禁至少等待 10 分钟，并尊重更长的 `Retry-After`。期满后仍需手动启动。 |
| `AUTH_REQUIRED` | 回官网重新登录。 |
| 超时、断网、无法解释的回执 | 显示「结果待核实」，保留该请求的未决标记。可主动只读核验。记录读取失败或暂未出现时保留原始提交结论。 |

每次启动只有一次正式 POST。所有手动新申请之间至少间隔 10 秒。前序失败也可能消耗写额度，实际可提交性由馆方决定。已经核验的同一时段如在官网取消，后续新申请先查官方记录。

## 诊断字段

- `plannedAt` 是计划时刻。`dispatchAt` 在签名、必要的未决标记完成后，紧邻浏览器 `fetch` 调用采样。`requestStartAt` 是可匹配时取得的浏览器 Resource Timing 请求起点。链路上第一个数据包和馆方收包时刻需网络端证据才能确定。
- `delayFrom20Ms` 是客户端发出相对该次北京时间开放锚点的毫秒数。`inWindow` 仅用于整点模式。`WINDOW_MISSED` 表示超窗。`hiddenDuringWait` 保留曾隐藏的观察，具体是系统挂起还是主线程受阻可能无法区分。
- `responseAt` 和 `httpMs` 记录收到 HTTP 响应头的时刻和耗时。`httpStatus`、`businessCode`、`businessResult`、`result`、`verification` 分别记录 HTTP、业务和官方核验。`sends` 按浏览器实际接手的调用计数。若进程恰在持久化意图和交出请求之间消失，次数与发出时间可为 `null`。
- 日志导出使用字段白名单。未知业务码在导出中显示 `OTHER`，中文理由使用映射后的类别。原始业务文本仅在当前面板显示。Cookie、学号、UID、账户散列、请求体和签名均不进入导出。
