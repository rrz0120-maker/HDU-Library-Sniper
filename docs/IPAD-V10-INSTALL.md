# iPad V10.0 Lite 安装与回滚

1. 在 Safari 的 Userscripts 中停用 V9 和其他 HDU 预约脚本。关闭原馆方标签页。保留浏览器站点数据，V10 与 V9 共用原有未决请求及限流保护。
2. 在「文件」中解压 HDU_iPad_V10.0_Lite.zip，把 HDU_iPad_V10.0_Lite.user.js 放入 Userscripts 选定的目录，启用扩展及脚本，允许其在杭电预约站点运行。
3. 打开并正常登录 [杭电预约官网](https://hdu.huitu.zhishulib.com/)。右下角应出现 **V10.0 · 162**。脚本在 HTTPS 顶层页面运行，需要支持 Web Locks 的 Safari 和可写的站点存储。
4. 核对系统北京时间、目标日期和时段。整点模式预约当晚开放的后天，默认宋韵云图四楼 162 号、09:00–22:00、20:00:01.200 触发，可设 800–2000 ms。点启动并看到「等待20:00」后保持 Safari 前台、屏幕常亮。「立即真实预约」会实际提交，请仅在本人需要预约时使用。
5. 「最近 30 次运行」可在同源刷新和重新打开后查看、复制 JSON。清空历史仅删除归档，当前标签页的上次回执和未决保护仍可存在。点「核验」会按原登录会话只读查询。若存储报错，立即复制本次日志，剪贴板不可用时可长按文本复制。

**实机验收 · REAL_DEVICE_PENDING**　先在零提交的待命任务上检查停止、历史复制、刷新恢复与横竖屏。请在自己原本就要进行的正常预约中记录 iPadOS、Safari、Userscripts 版本、前后台情况、计划和发出时间、HTTP 和业务回执，并到官网核对房间、座号、日期与时段。仅在有真实成功回执与对应官方记录后登记 iPad 高峰成功。清除站点数据、无痕会话结束或系统回收数据会影响本地恢复。

**回滚**　停止未发送的待命，停用 V10 并关闭馆方标签页，然后启用 V9 或解压下方原版 ZIP 安装。已发出且结果不明时，先在官网核对该时段。回滚后可在再次打开 V10 时读取保留的 V10 历史。[固定提交的 V9 ZIP](https://raw.githubusercontent.com/rrz0120-maker/HDU-Library-Sniper/bcaec606305bf122d64399f34db520f0beb38241/releases/HDU_iPad_V9_Lite_9.0.0.zip)
