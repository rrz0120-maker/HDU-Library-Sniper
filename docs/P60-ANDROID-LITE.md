# P6.0 Lite：一加安卓手机使用说明

版本 **6.0.0**，每天北京时间 20:00，预约后天宋韵云图（四楼）**162**，08:00–22:00、50400 秒、1 人。每天需要重新授权；最多一次正式预约提交，不重试、不换座。无需电脑常驻、Docker 或云服务器。

## 安装并保留旧数据

1. 使用之前成功运行 P5.2/P5.3 的 **同一个 Firefox 普通浏览配置、同一个校园账号**。不要使用隐私窗口，不要清除官网站点数据、IndexedDB 或 localStorage。
2. 打开 Tampermonkey 管理面板，将 P5.2（安装文件名含 `p51`）和 P5.3 的开关设为停用。**只停用，不卸载、不重置数据**。关闭其他已打开的官网标签页，避免其中的旧脚本继续运行。
3. 在 Firefox 点击上方 `.user.js` 链接，核对名称「杭电图书馆 P6.0 Lite 每日162」和版本 `6.0.0`，在 Tampermonkey 中安装。新名称、namespace 和文件独立，不覆盖旧安装文件。
4. 打开 [杭电图书馆官网](https://hdu.huitu.zhishulib.com/#!/Space/Category/list)，正常登录。页面右下角应只有 P6 悬浮入口，默认收起。无需输入或导出 Cookie、UID、密码。

P5.2 的永久成功凭据仍是跨版本防重复条件。找不到该凭据时会停止，不提供清库、伪造凭据或重新获取写入预算的操作。P5.3 已实战的 2026-11-19 08:00–22:00 时段在 P6 中永久禁止再次提交。

## 首次只读检查

展开入口，保持授权框**未勾选**，点击「启动今日抢座」。这时只做演练：验证登录、日期范围、14 小时规则、座位映射、已有预约、时间样本和存储，显示「只读检查通过」，不会在 20:00 自动提交。

诊断日志中可查看结果；缺少登录、时间样本异常、座位映射变化、日期规则不符、已有冲突或旧任务未决时会安全停止。当天开放窗口已过仍可做只读检查。官网只读座位查询的 HTTP 方法可能为 POST，但它不是正式 `bookSeats` 预约写入。

请先在一加手机验证展开/收起、授权默认未选、只读结果、日志复制和旧数据保留。这些真机项目尚未由本次开发环境验证。

## 每天 19:59–20:00

1. 19:59 左右打开官网并保持正常登录，展开 P6。
2. 核对「今日任务日期 → 目标预约日期」、四楼 162、08:00–22:00。确认馆方仍允许当天 20:00 开放后天，以及该 14 小时时段。
3. 勾选标有**当天日期**的授权框，点击「启动今日抢座」。正式准备只允许在 **19:58 至 20:00 前**发起；勾选本身不会启动。
4. 确认进入正式待命。可以收起面板，入口会继续显示倒计时。保持 Firefox 前台、屏幕唤醒、网络正常；此时不要切换微信、标签页或锁屏。
5. 合法开放门禁通过后，仅向 162 提交一次。入口依次反馈请求状态、业务受理和记录核验结果。看到最终结果后按下表处理。

提前打开脚本不会自动授权；19:58 前点击正式启动也不会排队，到时必须再点击。20:00 后新启动不会补发。已在开放前待命的任务保留 P5.3 的保守时钟和最长 10 秒迟到截止线，用于正常计时误差；不是迟到后重新启动或重试的窗口，实际截止也受服务器时间上界和准备有效期限制。

## 悬浮反馈与人工接管

| 入口 | 含义与操作 |
|---|---|
| `162 · 00:15` | 正式待命；保持前台。 |
| `162 · 提交中` | 已进入一次提交流程；不要重复操作或刷新。收到 HTTP 头时面板会单独提示正在解析。 |
| `162 · 已受理，正在核验` | 服务器业务响应成功；尚未证明官方记录完整匹配。 |
| `162 · 已成功`（绿色） | 官方记录已核对日期、162、房间、08:00、50400 秒及有效状态。停止自动任务。 |
| `失败 · 手动接管`（红色） | 明确拒绝，必要的记录核查已完成；展开看原因，可收起面板回官网人工操作。认证失效或限流应先按馆方要求处理，不绕过限制。 |
| `结果待确认`（橙色） | 404、超时、网络异常、发送后停止、未核验的成功响应或异常退出。**UNKNOWN 不等于失败**；先检查「官方我的预约」，不要直接重复占座或换账号再约。 |
| `已停止` / `今日窗口已结束` | 不再自动写入，不会自行恢复。 |
| `待命记录 · 仅查看` | 刷新/另一标签页读到了旧待命记录。本页不恢复任务；原标签页若仍有效可继续，停止按钮可停止本浏览器今日任务。 |

「收起」只控制显示；「停止任务」阻止后续写入，**不会取消预约**。请求已发送时，停止浏览器等待不能证明服务器未处理，结果保留 UNKNOWN。程序不操作微信或其他账号，不自动尝试 161/157。

## 查看结果、日志和近期任务

「查看结果」只读；已保存 SUCCESS 直接展示已有核验凭据，不重新生成首次成功时间。UNKNOWN 可核对官方记录：最多一次自动核验，总计最多三次脚本核验、间隔至少两秒，预算跨刷新保留。额度用尽后在官方页面人工核对，不重新提交。

展开「诊断日志与近期任务」可选择最近七个任务中的日期，再点「查看结果」。历史视图禁用正式启动；新的一天仍须重新授权。存在往日未决提交时，新任务会停止；日期变化不清除预算或 UNKNOWN。P6 对 P5.2/P5.3 数据只读，无法自动解除旧版未决记录。

点击「复制脱敏日志」。剪贴板不可用或被拒绝时，显示文本框，长按全选复制。日志不包含 UID、姓名、Cookie、密码、账号哈希、认证原文或签名。首次请求/响应/核验时间只记录一次，后续查看单独记录 `lastReviewedAt`。不要清库来排障或重复测试。

## 手机限制

- 官网局部 404、SPA 内容更新或悬浮节点被移除时，只恢复原组件，任务不会重启。整页导航、Firefox 原生错误页面、页面上下文销毁或系统暂停时，脚本可能无法继续显示或运行。
- 离开前台、锁屏、停止后不会自动恢复写入；每天准点触发依赖手机处于前台且可执行。恢复官网后可查看持久化结果，不能重发已消费任务。
- P6 没有后台服务、自动每日授权或无人值守能力；「每日」指日期自动生成，仍要每天主动启动。可选震动未加入，以免引入不必要的兼容性要求。
- 校时使用 HTTP Date 秒级样本的保守区间，不承诺毫秒级校准或固定发出延迟。一次 P5.3 高峰成功不代表长期成功率；P6 尚待真机验收。

回退时仅停用 P6 并保留数据。P5.3 只支持原固定日期，不能用旧版本重跑今日任务；P5.2 已消费的预算也不能重置。原安装包、旧分支和提交均保留。
