原项目依据直接沿用 [P5.3 定点来源清单](evidence/p53/sources.json)、[馆方限制](HUITU-LIMITS.md) 及 [P5.2 日期控件证据](evidence/p52/date-control.json)，没有全仓库重新研究或移植轮询、预锁、重试。`max_date` 仍为排他上界。预热读取当前合法开放日期，仅证明 162 内部映射，不能把旧日期的空闲状态当成未来日期的可用性。

正式准备在 19:58 至 20:00 前；仅当日显式勾选并点击可待命。放行必须同时满足手机时间和保守馆方时间下界到达 20:00，保留 P5.3 最长十秒迟到截止线及准备有效期。20:00 后不能创建新待命任务，冻结/迟到不补发。

正式请求前持久化 `attempts=1` 和提交意图，之后状态如何显示都不释放预算。服务器已受理时 UI 为 VERIFYING，持久化记录继续 UNKNOWN 防重复；精确核验后才 SUCCESS。每任务最多一次自动记录核验、总计三次记录核验，遵守两秒最小间隔；LIMITED/AUTH/停止后不继续自动请求。超时、404 等不重发。

P5.2 成功凭据仍必须存在且只读。P6 永久禁止 P5.3 固定时段的新写入，因此未修改的旧脚本无法与 P6 对该时段竞争。P5.3 已成功/明确失败的固定停止标记不影响未来日期；P5.3 未决写入和 P6 其他日期未决写入继续阻止新正式任务。不提供清库或复位预算功能。新标签页无需登录即可发出本浏览器当日停止信号；停止信号不会扩散至下一天。

## 时间、日志与 UI 解释

`firstDispatchAt` 是浏览器调用 fetch 前的客户端观测，不是抓包测得的实际发包时间；`firstResponseAt` 是 fetch 返回响应头；`firstBusinessResultAt` 是 JSON 解析完成；`firstServerSuccessAt` 是首次成功业务响应；`firstRecordVerifiedAt` 是首次匹配官方记录。首次值只能补空，后续查看写 `lastReviewedAt`。提交次数不能由这些展示字段重置。

`dispatchToHeadersMs` 包含网络、排队及服务端响应；不虚构单独的服务端处理耗时或上传耗时。`bodyDecodeMs` 包含响应体读取和 JSON 解析，不保证只是 CPU 解析。UI 分别记录状态更新、DOM 更新耗时和有效 rAF 渲染机会，**不等于用户实际看到结果的精确时刻**。若页面在下一帧前停止或状态已改变，渲染机会字段可以缺失。

局部 DOM 移除仅记录可观测 `UI_REATTACHED`；页面结束记录 `PAGE_CONTEXT_END`。不根据页面文字推断 HTTP 状态，也不增加网络请求专门探测官网 404。查询请求错误、正式请求错误、业务结果、核验、UI 反馈分开保存。日志允许导出当前与最近七个任务，每个任务保留必要事件，不包含账号哈希、UID、姓名、Cookie、密码、认证原文和签名。

诊断存储故障不重新提交；原子意图写入失败则不发送请求。突然关机可能使最后几条异步诊断未落盘，但在 fetch 前已提交的意图继续消耗预算，不能因缺少响应日志推断未预约。

## P5.3 真实实战基线

[脱敏基线 JSON](evidence/p60/p53-real-peak.json) 标记 `REAL_PEAK_TEST_PASS`。证据是用户本次提供的实测指标、事件摘录及成功确认；本轮没有独立读取原始截图或完整原始日志。

2026-11-17，一加 Android + Firefox + Tampermonkey，在无云服务器条件下，一次提交、零自动重试，官方记录确认 2026-11-19 四楼 162、08:00–22:00、50400 秒。准备 19:59:04.630 → 19:59:05.482，共 852ms；fetch 调用 20:00:00.760；响应头 20:00:04.340；业务成功 20:00:04.341。请求至响应头 3579ms、总 HTTP 3580ms、记录核验用时 1612ms。

21:57:42.327 的导出 `RECORD_VERIFIED` 可能来自后续查看，**不作为首次核验时间**，报告中首次核验字段为 null。HTTP Date 样本 RTT 64ms、手机差值 471ms 不等于毫秒级同步精度。一次实战无法推导长期成功率；这些真实指标属于 P5.3，不是本次 P6 Mock 性能。

```bash

npx playwright test --config playwright.p60.config.ts
npx playwright test --config playwright.p53.config.ts
npx playwright test --config playwright.userscript.config.ts
npx tsc --noEmit
npx biome check src/userscript/p53 src/userscript/p60 src/userscript/transport.js \
  tests/userscript-p60 scripts/build-userscript-p60.mjs playwright.p60.config.ts package.json
(cd userscripts && sha256sum -c SHA256SUMS)
```
